# KidsInspiring Nation (KIN) Website

Raising the Builders of Tomorrow.

This is a React-based website for KIN, featuring an Impact Dashboard and a modern, responsive design.

## Tech Stack
- React 19
- Vite
- Recharts (for Dashboard)
- Lucide React (for Icons)
- Tailwind CSS (for styling)

## Deployment
Deployed to GitHub Pages via GitHub Actions.
